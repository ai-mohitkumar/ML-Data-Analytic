# Streamlit Dashboard Guide

## Quick Start
```
streamlit run streamlit_intelligent_dashboard.py
```

## Features
- Intelligent clustering results (AutoML: KMeans/DBSCAN/Hierarchical)
- Hybrid scoring + **ICSO** metric display
- PCA/LDA visualizations (2D/3D)
- Cluster profiles
- Anomaly detection (Isolation Forest)
- Recommendations & insights
- **Real-time Prediction**: input a new user row and predict the nearest cluster

See QUICKSTART.md for full setup.
